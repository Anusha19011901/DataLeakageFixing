Objective:
In this assignment, you will visit the Titanic ML pipeline. That version of the pipeline actually contains a subtle but important problem: data leakage.

Your job is to identify where the leakage is happening, explain why it’s a form of leakage, and then correct it by rewriting the code properly.

What you need to do:

  1. Review the demo pipeline
    Go to the Titanic pipeline and review it.

  2. Find the leakage
    Carefully read through the preprocessing and feature engineering steps. Look for any point where information from the test set may be unintentionally influencing the training set.

    Hint: Think about how missing values were filled, and what data was used to compute those fill values.

  3. Explain the problem
    In a short comment or text cell:

    • Point out exactly where the leakage happens (mention the specific line or transformation).

    • Explain why it’s a problem — in other words, how it violates the principle of keeping test data separate from training data.

  4. Fix the code
    Modify the pipeline so that the imputation or transformation uses only the training data to compute any statistics (like medians or modes), and then applies them to both the train and test sets.

  5. Submit the fixed version
    • Include the corrected notebook with comments or a markdown cell explaining your fix.

    • Make sure the new version does not leak test data into training at any stage.

 

How you’ll be graded:

  • Correct identification of the leakage point

  • Clear explanation of why it’s leakage

  • A corrected version of the pipeline that avoids the issue

  • Clean and understandable code/comments

Tips:

  • Leakage is often unintentional, it happens when we apply transformations before splitting or when we compute statistics using the full dataset.

  • You can test for leakage by asking: “Did this transformation use test data in any way during training?”

  • Focus especially on steps like filling missing values, encoding, or scaling — those are common places where leakage hides.
